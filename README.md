# Lily Bloom 2.0.0 — Living Ponds

Цветущие кувшинки для **Minecraft Java 26.3 / Fabric**. Четыре цвета, три стадии цветения, маленькие листья и крупные кувшинки 2×2, 3×3 и 4×4. Цветы растут в болотах и мангровых болотах, срезаются ножницами и ставятся в горшки.

## Установка

Установите Java 25, Fabric Loader **0.19.5+**, Fabric API **0.163.0+26.3 или новее для 26.3** и `lilybloom-2.0.0+26.3.jar` в `mods/`. В одиночной игре достаточно установки на клиент. Для сервера нужна одинаковая версия и на сервере, и у всех игроков. Старый JAR мода удалите.

Существующие ID блоков сохранены. Перед обновлением сделайте резервную копию мира. Откат мира с новыми признаками на старые версии не поддерживается.

## Управление и новые возможности

| Действие по кувшинке | Результат |
|---|---|
| Костная мука | Бутон → полураскрытый цветок → полный цветок |
| Ножницы | Срезать полностью открытый цветок |
| Присесть + ножницы | Переключить лист: круглый → овальный → с вырезом → с загнутым краем |
| Светящийся чернильный мешок | Светящийся цветок: свет 10 у открытого, 2 у бутона |
| Обычный чернильный мешок | Удалить свечение |
| Лунная пыльца | Ночное цветение: днём закрывается, ночью раскрывается |
| Пчелиные соты | Убрать ночной признак |
| Свеча / фонарь / фонарь душ по крупному листу без цветка | Поставить плавающий светильник |
| Присесть + пустая рука по листу со светильником | Снять светильник |
| Лопатка для пересадки | Забрать весь лист с цветком, стадией и признаками одним предметом |

Ночное время: 13000–22999 тиков. Цветок закрывается в течение пяти секунд после наступления дня, раскрывается за две ступени примерно за десять секунд ночи. Ночной цикл работает по игровым часам, в том числе после `/time set`. Обычный дневной рост использует случайные тики и настройки сервера.

Лопатка: одна палка снизу слева, один медный слиток сверху справа в сетке 2×2. Прочность — 256 пересадок. Лунная пыльца: осколок аметиста + голубой цветок кувшинки, получается 4 штуки, порядок не важен.

Светильники ставятся на все три крупных размера и занимают место цветка. Поддерживается обычная неокрашенная свеча. Свет: свеча 12, фонарь 15, фонарь душ 10. Установленная свеча сразу горит. Сдвиг формы или признаков с любой части крупного листа меняет весь лист.

## Селекция

Расположите две полностью открытые кувшинки разных цветов на одном уровне воды, в пределах шести блоков по X и Z от центра первого листа. Используйте костную муку по одному из родителей: расходуется одна штука и появляется один маленький лист-потомок с бутоном. Подходят маленькие и крупные родители.

Потомок получает цвет, форму листа и ночной признак одного случайно выбранного родителя. Узор тоже наследуется, дополнительно каждый потомок имеет шанс 1/8 на мутацию — крапчатые или полосатые лепестки. Светящееся покрытие наносится отдельно. Узор относится к растению: срезанный отдельный цветок остаётся обычным цветком своего цвета.

Подсказки в инвентаре показывают форму, узор, ночное цветение и свечение. Особые маленькие листья сохраняют признаки после срезания цветка; новый цветок отрастает того же цвета. Обычный круглый дневной лист без особых признаков после срезания возвращается в ванильную кувшинку.

## Крупные кувшинки

| Размер | ID | Рецепт | Цветков при срезании |
|---|---|---|---|
| 2×2 | `lilybloom:medium_lily_pad` | Четыре обычные кувшинки квадратом | 1 |
| 3×3 | `lilybloom:large_lily_pad` | Четыре кувшинки крестом вокруг костной муки | 2 |
| 4×4 | `lilybloom:giant_lily_pad` | Восемь кувшинок вокруг костной муки | 2 |

Ставятся на свободную воду целиком. Поломка любой части убирает весь лист с одним выпадением предмета. При обычной поломке крупного листа открытый цветок и светильник выпадают отдельно; форма и признаки остаются в предмете листа. Для переноса вместе с цветком, стадией или светильником используйте лопатку.

Розовые ID из старых версий, остальные цвета, рецепты красителей, горшки, взаимодействие с пчёлами, раздатчики и генерация в новых болотных чанках сохранены. Четыре цвета: розовый, белый, жёлтый и голубой.

## Ресурспаки и настройки

Встроены текстуры 16×, 32× и 64×, включая новые формы и узоры. HD выбирается автоматически по текстуре обычной кувшинки активного ресурспака. Настройки `config/lilybloom.json`:

- `hdTextures`: `auto`, `32x`, `64x` или `off` (не управлять паками автоматически).
- `glowParticles`: `true` по умолчанию; `false` отключает небольшие частицы свечения на клиенте.
- `naturalBlooming`: естественное появление и рост бутонов, по умолчанию `true`.
- `budChance`: 150; `growChance`: 20 — шанс 1/N за случайный тик.
- `maxBloomingNearby`: 3; `onlyDuringDay`: `true`; `worldGeneration`: `true`.

## Сборка

JDK 25: `./gradlew build`. Результат в `build/libs/`. Готовые ресурсы уже включены в исходники. Для их повторной генерации нужен Pillow и официальный клиентский JAR 26.3: `python tools/generate_v2.py /path/to/minecraft-26.3.jar`.

`src/testmod/` содержит отдельные проверочные моды для сервера и клиента; в обычный релиз они не входят. Подробности проверки: [docs/TEST_REPORT.md](docs/TEST_REPORT.md). Английский changelog: [RELEASE_NOTES.md](RELEASE_NOTES.md).
