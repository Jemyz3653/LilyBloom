# Lily Bloom — цветущие кувшинки (Fabric, Minecraft 26.3)

Один мод для **сервера и клиента**: `lilybloom-1.2.1+26.3.jar` кладётся в `mods/` и на сервер, и каждому игроку.
Нужны Fabric Loader 0.19+ и Fabric API.

> Код, текстуры и модели мода созданы с помощью ИИ (Claude, Anthropic). Лицензия — MIT.

## Что добавляет

Четыре цвета: розовый, белый, жёлтый, голубой. Каждый цвет — отдельные блоки и предметы (как ванильные тюльпаны).

| Блок / предмет | ID (розовый / остальные) | Как получить |
|---|---|---|
| Цветущая кувшинка | `lilybloom:blooming_lily_pad`, `lilybloom:white_blooming_lily_pad`, `yellow_…`, `blue_…` | костная мука по кувшинке; сама расцветает; генерируется в болотах |
| Цветок кувшинки | `lilybloom:lily_flower`, `lilybloom:white_lily_flower`, `yellow_…`, `blue_…` | ножницы по распустившейся кувшинке |
| Цветок кувшинки в горшке | `lilybloom:potted_lily_flower`, `lilybloom:potted_white_lily_flower`, … | ПКМ цветком по пустому горшку |

Розовый сохранил ID из 1.0.x, поэтому уже поставленные в мире розовые кувшинки и цветы остаются на месте (распустившимися).

* **Стадии цветения** (`stage`): бутон → полураскрытый бутон → цветок. Бутон сам дорастает днём под открытым небом.
* **Костная мука** по обычной кувшинке (рукой или из раздатчика) — бутон случайного цвета
  (белый 35 %, розовый 30 %, жёлтый 20 %, голубой 15 %). Каждая следующая костная мука — на стадию дальше.
* **Выбрать цвет:** ПКМ цветком кувшинки нужного цвета по обычной кувшинке — сразу распустившаяся кувшинка этого цвета.
* **Сама расцветает:** обычные кувшинки под открытым небом днём изредка пускают бутон —
  поэтому цветы появляются и на уже сгенерированных прудах сервера, не только в новых чанках.
  Не больше 3 кувшинок с бутоном или цветком в области 7×3×7, чтобы пруд не зарастал целиком.
* **Генерация**: в новых чанках болот и мангровых болот (там же, где ванильные кувшинки) — все цвета и стадии.
* **Ножницы** по распустившейся кувшинке (рукой или из раздатчика) — выпадает цветок её цвета, остаётся обычная кувшинка.
  С бутона ножницы ничего не срезают. Сломанный бутон даёт обычную кувшинку, распустившаяся — саму себя.
* **Цветок кувшинки** горит, как обычные цветы, ставится на землю (трава, земля, мох, грядка — как любой цветок) и сажается в горшок.
  Крафтится в краситель (розовый, белый, жёлтый, голубой), годится для подозрительного рагу (дыхание под водой),
  компостируется, нравится пчёлам.

## Крупная кувшинка (4×4)

`lilybloom:giant_lily_pad` — круглый лист 4×4 блока с загнутым краем (как у виктории амазонской).

* **Крафт:** 8 обычных кувшинок вокруг костной муки. Ещё генерируется в болотах и мангровых болотах (в новых чанках), иногда сразу с цветком.
* **Ставится на воду**, как обычная кувшинка: нужно 4×4 свободной воды; лист уходит вперёд от блока, на который смотрит игрок.
* **Цветок** тех же четырёх цветов и стадий: костная мука даёт бутон случайного цвета и растит его; цветок кувшинки на листе — сразу распустившийся цветок этого цвета; днём под открытым небом бутон появляется и растёт сам.
* **Ножницы** (рукой или из раздатчика) срезают с распустившегося цветка 2 цветка кувшинки.
* Сломать любую часть — ломается весь лист, выпадает один предмет (и цветок кувшинки, если цветок был распустившимся). Лодки ломают его, как обычные кувшинки.
* Технически это 16 блоков с координатами части (`part_x`, `part_z`) и общим цветком (`flower`, `stage`); цветок рисует центральный блок (1, 1).

## Текстуры 32x и 64x (в стиле Faithful)

В мод встроены два ресурспака: «Lily Bloom 32x» и «Lily Bloom 64x» (цветы, бутоны, цветок кувшинки, предметы).
Они **включаются сами**, если ресурспак игрока делает обычную кувшинку 32x или 64x (Faithful 32x, Faithful 64x
и похожие паки), и выключаются, когда игрок возвращается к 16x. Лист цветущей кувшинки — это текстура обычной кувшинки
из текущего ресурспака, поэтому он всегда совпадает с соседними кувшинками.

Настройка клиента `hdTextures` в `config/lilybloom.json`: `auto` (по умолчанию), `32x`, `64x` — всегда этот пак,
`off` — мод не трогает паки, их можно включить вручную в списке ресурспаков.

## Настройки — `config/lilybloom.json` (на сервере)

```jsonc
{
  "naturalBlooming": true,   // кувшинки сами пускают бутоны, бутоны сами распускаются
  "budChance": 150,          // шанс бутона 1 из N за случайный тик (в 1.0.x было bloomChance = 25 сразу до цветка)
  "growChance": 20,          // шанс следующей стадии 1 из N за случайный тик (~20 минут на стадию)
  "maxBloomingNearby": 3,    // предел кувшинок с бутоном/цветком в 7×3×7 для самостоятельного цветения (0 — без предела)
  "onlyDuringDay": true,     // бутоны появляются и растут только днём
  "worldGeneration": true,   // генерация в новых чанках болот
  "hdTextures": "auto"       // клиент: текстуры 32x/64x — auto, 32x, 64x или off
}
```

Случайный тик достаётся конкретному блоку в среднем раз в ~68 секунд (при `randomTickSpeed` = 3).
Файл из 1.0.x обновляется сам: `bloomChance` убирается, добавляются `budChance` и `growChance`.

## Сборка и публикация

* Сборка: каждый push запускает `.github/workflows/build.yml`, готовый jar — в Artifacts. Локально: `./gradlew build` (JDK 25), результат в `build/libs/`.
* Публикация: `.github/workflows/release.yml` (запуск вручную) выполняет `./gradlew build publishMods` и выкладывает версию на Modrinth, CurseForge и GitHub Releases.
  ID проектов — в `gradle.properties` (`modrinth_id`, `curseforge_id`), токены — в секретах репозитория `MODRINTH_TOKEN` и `CURSEFORGE_TOKEN`.
  Текст изменений версии — `RELEASE_NOTES.md`, история — `CHANGELOG.md`.
