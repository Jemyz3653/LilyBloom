# Lily Bloom — цветущие кувшинки (Fabric, Minecraft 26.3)

Один мод для **сервера и клиента**: `lilybloom-1.0.0+26.3.jar` кладётся в `mods/` и на сервер, и каждому игроку.
Нужны Fabric Loader 0.19+ и Fabric API.

> Код, текстуры и модели мода созданы с помощью ИИ (Claude, Anthropic). Лицензия — MIT.

## Что добавляет

| Блок / предмет | ID | Как получить |
|---|---|---|
| Цветущая кувшинка | `lilybloom:blooming_lily_pad` | костная мука по обычной кувшинке; сама расцветает; генерируется в болотах |
| Цветок кувшинки | `lilybloom:lily_flower` | ножницы по цветущей кувшинке |
| Цветок кувшинки в горшке | `lilybloom:potted_lily_flower` | ПКМ цветком по пустому цветочному горшку |

* **Цветущая кувшинка** — отдельный блок, не blockstate обычной. Ставится на воду как кувшинка, лодка её ломает, с неё падает она сама.
* **Костная мука** по обычной кувшинке (рукой или из раздатчика) — сразу превращает её в цветущую.
* **Сама расцветает**: обычные кувшинки под открытым небом днём иногда расцветают от случайных тиков —
  поэтому цветущие появляются и на уже сгенерированных прудах сервера, не только в новых чанках.
  Не больше 3 цветущих в области 7×3×7, чтобы пруд не зарастал целиком.
* **Генерация**: в новых чанках болот и мангровых болот (там же, где ванильные кувшинки).
* **Ножницы** по цветущей кувшинке (рукой или из раздатчика) — выпадает цветок кувшинки, остаётся обычная кувшинка.
* **Цветок кувшинки** ставится на землю (трава, земля, мох, грядка — как любой цветок) и сажается в горшок.
  ПКМ цветком по обычной кувшинке — цветок возвращается, кувшинка снова цветущая.
  Крафтится в розовый краситель, годится для подозрительного рагу (дыхание под водой), компостируется, нравится пчёлам.

## Настройки — `config/lilybloom.json` (на сервере)

```jsonc
{
  "naturalBlooming": true,   // кувшинки сами расцветают
  "bloomChance": 25,         // шанс 1 из N за случайный тик (~раз в полчаса на кувшинку рядом с игроком)
  "maxBloomingNearby": 3,    // предел цветущих в 7×3×7 для самостоятельного цветения (0 — без предела)
  "onlyDuringDay": true,     // расцветать только днём
  "worldGeneration": true    // генерация в новых чанках болот
}
```

## Сборка и публикация

* Сборка: каждый push запускает `.github/workflows/build.yml`, готовый jar — в Artifacts. Локально: `./gradlew build` (JDK 25), результат в `build/libs/`.
* Публикация: `.github/workflows/release.yml` (запуск вручную) выполняет `./gradlew build publishMods` и выкладывает версию на Modrinth, CurseForge и GitHub Releases.
  ID проектов — в `gradle.properties` (`modrinth_id`, `curseforge_id`), токены — в секретах репозитория `MODRINTH_TOKEN` и `CURSEFORGE_TOKEN`.
  Текст изменений версии — `RELEASE_NOTES.md`, история — `CHANGELOG.md`.
