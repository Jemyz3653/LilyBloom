# Version numbering

- Bug fixes increment the patch version: 2.0.0 → 2.0.1.
- Feature updates increment the minor version: 2.0.1 → 2.1.0.
- Major releases increment the major version and reset minor/patch: 1.x.x → 2.0.0.
- The +26.3 suffix identifies the target Minecraft version.

The Living Ponds update is 2.0.0 on GitHub, CurseForge and in the mod metadata.
