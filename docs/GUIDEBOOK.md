# Lily Bloom — Guide Book

Standalone bilingual (Russian / English) field guide to Lily Bloom 2.0.0 for Minecraft Java 26.3 / Fabric. This website does not modify or add files to the mod.

Buildless HTML, CSS and JavaScript. The deployable site is in `dist/`. No third-party runtime, tracking or network dependencies.

## Contents

- Nine crafting recipes imported from the release JSON, with exact layouts, ingredient totals and item IDs.
- Twenty illustrations rendered from actual mod models and textures; original in-game day/night views.
- Growth, harvesting, transplantation, plant traits, nocturnal behaviour, light levels, grouped inheritance and mutation rules.
- Search, recipe filters, interactive atlas, day/night comparison, keyboard shortcuts and responsive mobile navigation.
- Language selection persists in the browser and can be selected with `?lang=ru` or `?lang=en`.

The code-audited fact sheet is in `CONTENT-AUDIT.md`. Recipe source data is in `dist/recipes.js`.
